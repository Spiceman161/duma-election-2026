Здесь находятся **данные 2026 года**, документация и инструменты распаковки. Код сайта uiks.top в этот репозиторий не входит.

> Это исследовательский снимок сохранённых материалов, а не удостоверенные окончательные официальные итоги. Название и год выборов унаследованы от исходной поставки; карточка выборов заново не проверялась. Наличие протокола и наличие координат — разные характеристики полноты.

## География и её точность

Добавлены **83 372** точки старой карты; **2 627** координат Yandex из поставки сохранены без изменения. Сопоставление выполнено по **региону и номеру УИК**, только при единственном совпадении с обеих сторон. Принадлежность к округу условием сопоставления не была.

Непустые исходные адреса и координаты не заменялись. Новое геокодирование не выполнялось. Синтетические точки без подтверждённой географии УИК исключены.

| Поле | Как использовать |
| --- | --- |
| `address_origin` | `cik_commission_service` — исходный адрес ЦИК; `historical_map` — адрес старой карты |
| `coordinate_source` | `supplied_yandex_geocoding` или `historical_map` |
| `locality_source` | Происхождение населённого пункта |
| `geography_match_method` | `unique_region_and_uik_number` — единственное совпадение |
| `coordinate_approximate` | 0/1 для Yandex; пусто/NULL для унаследованных точек без новой оценки |

У 325 точек Yandex нет сочетания `exact` + `house`; они помечены `coordinate_approximate=1`. Унаследованные точки не проверялись заново, поэтому пустое значение не означает подтверждённую точность. Поле `address_status` описывает исходный поиск ЦИК, а не качество впоследствии добавленного адреса.

## Чего не хватает

- **5 382 УИК без координат:** 2 800 обычных УИК с партийными протоколами, 333 вне обычного регионального слоя и 2 249 участков четырёх регионов без партийных протоколов.
- **4 831 отсутствующий протокол**, считая оба вида бюллетеня; поимённый список — `missing_protocols.csv`.
- Партийные протоколы не собраны для Луганской Народной Республики, Донецкой Народной Республики, Запорожской и Херсонской областей. Их известные УИК сохранены в реестре.
- Исходные необработанные ответы сервиса в архив не включены (`raw_included=false`); сохранены извлечённые таблицы и сведения об источниках, включая агрегированные хеши исходных файлов.
- Многие протоколы имеют статус `preliminary`; повторные протоколы отмечены `recounted`. Анализируйте статус отдельно, не считайте снимок подтверждением окончательности результатов.

По партийным спискам обычных УИК есть 89 132 протокола: 88 799 в 85 регионах и 333 вне обычного регионального слоя. У 41 такого протокола нулевой знаменатель для доли голосов.

## Пример расчёта

Карта использует **голоса ЕР ÷ (действительные + недействительные бюллетени) × 100%**. Региональные суммы включают участки без координат. Для нулевого знаменателя результат — NULL. Другие исследования могут явно выбрать другую методику.

Запустите [examples/er_by_region.sql](examples/er_by_region.sql) в `data/elections.sqlite`:

```sql
SELECT p.region_name,
       SUM(r.votes) AS er_votes,
       SUM(p.valid_ballots + p.invalid_ballots) AS ballots,
       100.0 * SUM(r.votes) /
       NULLIF(SUM(p.valid_ballots + p.invalid_ballots), 0) AS er_percent
FROM protocols AS p
JOIN party_results AS r USING (protocol_key)
WHERE p.dataset = 'uik'
  AND p.ballot_type = 'party_list'
  AND r.party_id LIKE '%edinaya-rossiya%'
GROUP BY p.region_name;
```

## Воспроизводимость

В Git находятся документация, схема и примеры. Данные опубликованы двумя ZIP с Deflate во вложениях датированного Release. Скрипт [package_release.py](scripts/package_release.py) предназначен для сопровождающих: он проверяет исходную поставку, переупаковывает данные по форматам и проверяет SHA-256 каждого исходного и выходного файла. Для использования скачанных данных скрипт не нужен.

Исходные байты таблиц и SQLite сохранены. Переупаковка меняет SHA-256 ZIP, поэтому актуальные контрольные суммы пакетов находятся в Release. [SOURCE_SHA256SUMS](docs/SOURCE_SHA256SUMS) относится к исходным файлам поставки; `SHA256SUMS` внутри каждого нового ZIP — к файлам именно этого пакета. [Исходная документация](docs/SOURCE_README.ru.md) и `manifest.json` сохранены как метаданные поставки: упоминания ZIP LZMA в них относятся к прежней упаковке.

Проверены целостность SQLite, внешние ключи, численность таблиц, суммы голосов и совпадение географических значений CSV/SQLite. Результаты — [validation_summary.json](docs/validation_summary.json). Исходные таблицы голосования при добавлении географии не менялись.
