# Госдума 2026 — исследовательский снимок 30.09.2026

Репозиторий и обновления: https://github.com/Spiceman161/duma-election-2026

Доступны два ZIP с обычным сжатием Deflate: CSV и SQLite. Каждый содержит полное представление одного снимка; выбирайте нужный формат. Python и Git для распаковки не нужны. Если скачаны оба архива, распакуйте их в разные папки.

CSV: все таблицы лежат в корне архива, кодировка UTF-8, первая строка — заголовки. Крупные таблицы могут превышать ограничения электронных таблиц; используйте инструменты обработки данных.

SQLite: откройте elections.sqlite в программе с поддержкой SQLite. Пример запроса — examples/er_by_region.sql. source_ledger.csv в docs/ дополнительно сохраняет атрибуцию источников.

Оба формата сохраняют все партии, кандидатов, оба вида бюллетеня, ДЭГ и строки протоколов. Это собранный исследовательский снимок, а не удостоверенные окончательные официальные итоги. Название и год унаследованы от материалов сбора; карточка выборов заново не проверялась. Встречаются preliminary/recounted; raw-ответы сервиса не включены. ДЭГ нельзя автоматически присоединять к физическим УИК.

docs/schema.json описывает поля; docs/manifest.json и docs/validation_summary.json сохраняют метаданные исходной поставки. docs/SOURCE_README.ru.md — исходная документация: её замечания об упаковке LZMA относятся к поставке, а текущие два ZIP используют Deflate. Голосование и байты исходных таблиц при переупаковке не менялись. SHA256SUMS в корне содержит контрольные суммы файлов именно этого пакета.

Унаследованная география не проверялась заново; пустая оценка точности не означает подтверждённую точность. Источники исторической географии: RED (https://doi.org/10.1038/s41597-026-07590-9) и Harvard Dataverse (https://doi.org/10.7910/DVN/DFGNTP), CC BY 4.0 для соответствующих материалов. Новая общая лицензия сторонним данным не назначается. При цитировании указывайте репозиторий, дату снимка и источники использованных материалов.
